# Missão ENEM · 3º ano

Revisão gamificada de Matemática 3 para o ENEM das turmas **M31, M32 e PV** do Curso G9, com o Prof. Mateus Bibiano.

**Acesse:** https://mateusbibiano.github.io/missao-enem-3ano/

- 34 questões em 7 fases: Polígonos, Triângulos, Quadriláteros e Ângulos, Circunferências e Círculos, Poliedros, Corpos Redondos e Tópicos de Analítica.
- Cada fase só é liberada quando todas as questões da fase anterior são acertadas, e o professor libera cada fase na aula.
- XP, sequência de acertos, níveis, estrelas, medalhas e certificado com código de verificação.
- O progresso fica no navegador do aluno e é enviado ao professor para o ranking da turma.

O site é um único arquivo (`index.html`).
